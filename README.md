# Аддон для обнаружения неиспользуемых нод метариалов
За "неиспользумые" приняты все ноды, которые не подключены к material Output напрямую или через цепочку других нод.
Версия Blender - 4.4

## Использование
Есть два варианта.
1) Заархивировать папку addon в .zip.  Запустить Blender, добавить аддон через edit -> preferences -> Add-ons -> Install from Disk. Аддон будет доступен в N-Panel только в окне редактирования нод материалов в новопоявившемся снизу разделе Tools. 
2) Запустить из терминала скрипт blender-launcher.py. Перед запуском проверить корретность пути BLENDER_EXE. Если путь указан верно, то аддон зарегистрируется автоматически. В таком режиме открыть консоль невозможно, вывод будет в терминал. Если вывода в терминал не происходит, воспользоваться вариантом 1.

Работа аддона запускается единственной кнопкой `Detect Unused M-nodes`
